## ui画图

- [ProcessOn](https://www.processon.com/): A collaborative online diagramming tool supporting flowcharts, mind maps, org charts, and UML diagrams. Ideal for team collaboration.
- [draw io](https://app.diagrams.net/): Free and open-source diagram software with a wide range of templates and integrations with Google Drive, OneDrive, etc.
- [BoardMix](https://boardmix.cn/): An online whiteboard platform for brainstorming, diagramming, and project management.
- [Excalidraw](https://excalidraw.com/): Hand-drawn style diagramming tool, perfect for quick sketches and wireframes with a sketchy aesthetic.
- [Miro](https://miro.com/): Digital whiteboard for remote collaboration, visual thinking, and agile workflows.
- [textik](https://textik.com/#a3330b21a337ef9e): Text-based diagram editor that converts text descriptions into visual diagrams.
- [asciiflow](https://asciiflow.com/#/): Simple tool for creating ASCII art diagrams, useful for text-based documentation.
- [Lucidchart](https://www.lucidchart.com/): Professional diagramming tool with advanced features and integrations with tools like Jira and Confluence.
- [Canva](https://www.canva.com/): User-friendly design tool that includes diagramming capabilities, great for non-technical users.

## Tips for Using Drawing Tools

- **Choose the right tool**: Use UI-based tools for collaborative and visual design work, while code-based tools are better for version-controlled, reproducible diagrams in software projects.
- **Integration with development**: Code-based tools like PlantUML and Mermaid can be integrated into CI/CD pipelines to automatically generate documentation diagrams.
- **Export options**: Most tools support exporting to PNG, SVG, or PDF for use in reports and presentations.
- **Learning resources**: Check official documentation or tutorials for advanced features, such as custom styling in Mermaid or complex layouts in draw.io.
