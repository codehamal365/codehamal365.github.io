# Linux中重新部署jar程序

在 Linux 服务器上重新部署 Java JAR 程序（如 Spring Boot 应用）时，需要停止旧进程并启动新版本。本文提供了一个简单的 Bash 脚本，用于自动化此过程。脚本使用 `jps` 命令查找进程，`kill` 停止它，然后使用 `nohup` 在后台重新启动。

## 前提条件
- 安装 JDK（Java Development Kit），确保 `java` 和 `jps` 命令可用。
- JAR 文件位于脚本执行目录，或使用绝对路径。
- 用户有权限执行脚本和运行 Java 程序。

## 基本脚本

```bash
#!/bin/bash

# 配置变量
JAR_NAME="MyApplicationBackend.jar"
PROCESS_NAME="MyApplicationBackend"
LOG_FILE="log.txt"

# Step 1: Find the PID of the target process
PID=$(jps -l | grep "$PROCESS_NAME" | awk '{print $1}')

# Step 2: Kill the process if it's running
if [ -n "$PID" ]; then
    echo "Killing process $PID..."
    kill -9 $PID
    sleep 2 # Wait a few seconds to ensure the process is terminated
    # Check if still running
    if ps -p $PID > /dev/null; then
        echo "Process still running, force killing..."
        kill -9 $PID
    fi
fi

# Step 3: Restart the process
echo "Restarting process..."
nohup java -jar $JAR_NAME > $LOG_FILE 2>&1 &
NEW_PID=$!
echo "New process started with PID: $NEW_PID"

# Optional: Wait a bit and check if it's running
sleep 5
if ps -p $NEW_PID > /dev/null; then
    echo "Process is running successfully."
else
    echo "Failed to start the process."
fi
```

## 使用方法
1. 将脚本保存为 `deploy.sh`，并使其可执行：`chmod +x deploy.sh`
2. 修改变量以匹配你的 JAR 文件和进程名。
3. 运行脚本：`./deploy.sh`

## 改进版本：带健康检查
以下是一个更健壮的版本，包括健康检查和错误处理：

```bash
#!/bin/bash

# 配置
JAR_NAME="MyApplicationBackend.jar"
PROCESS_NAME="MyApplicationBackend"
LOG_FILE="app.log"
HEALTH_CHECK_URL="http://localhost:8080/health"  # 假设应用有健康检查端点
MAX_RETRIES=3

# 函数：检查进程是否运行
is_process_running() {
    jps -l | grep -q "$PROCESS_NAME"
}

# 函数：健康检查
health_check() {
    if command -v curl > /dev/null; then
        curl -f -s "$HEALTH_CHECK_URL" > /dev/null
    else
        # 如果没有 curl，简单检查进程
        is_process_running
    fi
}

# 停止旧进程
if is_process_running; then
    PID=$(jps -l | grep "$PROCESS_NAME" | awk '{print $1}')
    echo "Stopping process $PID..."
    kill $PID
    for i in {1..10}; do
        if ! is_process_running; then
            break
        fi
        sleep 1
    done
    if is_process_running; then
        echo "Force killing..."
        kill -9 $PID
    fi
fi

# 启动新进程
echo "Starting new process..."
nohup java -jar $JAR_NAME > $LOG_FILE 2>&1 &
NEW_PID=$!
sleep 10

# 健康检查
for ((i=1; i<=MAX_RETRIES; i++)); do
    if health_check; then
        echo "Deployment successful!"
        exit 0
    fi
    echo "Health check failed, retrying... ($i/$MAX_RETRIES)"
    sleep 5
done

echo "Deployment failed after $MAX_RETRIES retries."
exit 1
```

## 注意事项
- 使用 `kill -9` 可能导致数据丢失，优先使用 `kill` 让应用优雅关闭。
- 确保日志文件不会无限增长。
- 对于生产环境，考虑使用 systemd 或 Docker 进行管理。
- 测试脚本在非生产环境中。
