## 🚀 快速开始

### 1. 安装 Rust

{% raw %}
```bash
# 使用 rustup 安装
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证安装
rustc --version
cargo --version
```
{% endraw %}

### 2. 选择学习路径

**系统学习**:
1. 阅读 [RUST_SUMMARY.md](RUST_SUMMARY.md) - 了解整体
2. 阅读 [RUST_GUIDE.md](RUST_GUIDE.md) - 系统学习
3. 按照 [RUST_ROADMAP.md](RUST_ROADMAP.md) - 制定计划

**快速上手**:
1. 阅读 [RUST_SUMMARY.md](RUST_SUMMARY.md) - 快速开始
2. 使用 [RUST_CHEATSHEET.md](RUST_CHEATSHEET.md) - 快速语法
3. 查看 [RUST_FAQ.md](RUST_FAQ.md) - 常见问题

**问题导向**:
1. 先查 [RUST_FAQ.md](RUST_FAQ.md) - 常见问题
2. 需要语法参考看 [RUST_CHEATSHEET.md](RUST_CHEATSHEET.md)
3. 需要资源看 [RUST_RESOURCES.md](RUST_RESOURCES.md)

### 3. 开始编码

{% raw %}
```rust
// main.rs
fn main() {
    println!("Hello, Rust!");

    // 变量和类型
    let x = 5;
    let mut y = 10;
    y = 20;

    // 函数
    fn add(a: i32, b: i32) -> i32 {
        a + b
    }

    println!("2 + 3 = {}", add(2, 3));
}
```
{% endraw %}

运行：
{% raw %}
```bash
cargo run
```
{% endraw %}
