## 🚀 快速开始

### 1. 安装 Rust

{% raw %}
```bash
# 使用 rustup 安装
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证安装
rustc --version
cargo --version
```
{% endraw %}

### 2. 选择你的学习路径

#### 路径 A: 系统学习 (推荐)
1. 阅读 [2026-02-03-Rust入门与高级指南](2026-02-03-Rust入门与高级指南) - 完整学习指南
2. 按照 [2026-02-03-Rust学习路线图](2026-02-03-Rust学习路线图) 制定计划
3. 使用 [2026-02-03-Rust快速参考手册](2026-02-03-Rust快速参考手册) 日常参考

#### 路径 B: 快速上手
1. 阅读 [2026-02-03-Rust快速参考手册](2026-02-03-Rust快速参考手册) - 快速语法
2. 查看 [2026-02-03-Rust常见问题解答](2026-02-03-Rust常见问题解答) - 解决问题
3. 参考 [2026-02-03-Rust学习资源索引](2026-02-03-Rust学习资源索引) - 寻找资源

#### 路径 C: 问题导向
1. 遇到问题先查 [2026-02-03-Rust常见问题解答](2026-02-03-Rust常见问题解答)
2. 需要语法参考看 [2026-02-03-Rust快速参考手册](2026-02-03-Rust快速参考手册)
3. 需要资源看 [2026-02-03-Rust学习资源索引](2026-02-03-Rust学习资源索引)

### 3. 开始编码

{% raw %}
```rust
// main.rs
fn main() {
    println!("Hello, Rust!");

    // 变量和类型
    let x = 5;
    let mut y = 10;
    y = 20;

    // 函数
    fn add(a: i32, b: i32) -> i32 {
        a + b
    }

    println!("2 + 3 = {}", add(2, 3));
}
```
{% endraw %}

运行：
{% raw %}
```bash
cargo run
```
{% endraw %}

## 🔧 常用工具

### 开发工具

{% raw %}
```bash
# 安装工具
cargo install rust-analyzer
cargo install cargo-flamegraph
cargo install cargo-bloat
cargo install cargo-audit
cargo install cargo-deny

# 日常使用
cargo new myapp          # 创建新项目
cargo build              # 构建
cargo run                # 运行
cargo test               # 测试
cargo check              # 检查
cargo fmt                # 格式化
cargo clippy             # 代码检查
cargo doc                # 生成文档
```
