## Kotlin知识点
- 委托
  委托是一种设计模式，其中一个对象通过委托给另一个对象来处理请求。在 Kotlin 中，可以使用 by 关键字实现属性委托。
  示例:
  ```kotlin
  class Delegate {
    operator fun getValue(thisRef: Any?, property: KProperty<*>): String {
      return "$thisRef, thank you for delegating '${property.name}' to me!"
    }
    operator fun setValue(thisRef: Any?, property: KProperty<*>, value: String) {
      println("$value has been assigned to '${property.name}' in $thisRef.")
    }
  }
  val myVar: String by Delegate()
  ```
- lambda
  Lambda 表达式是匿名函数，可以作为参数传递或赋值给变量。
  示例: val sum = { a: Int, b: Int -> a + b }
- 高阶函数
  高阶函数是将函数作为参数或返回函数的函数。
  示例: fun <T> lock(lock: Lock, body: () -> T): T { ... }
- 内置高阶函数(let,also,run)
  - let: 对对象执行操作并返回结果。
  - also: 对对象执行操作并返回对象本身。
  - run: 对对象执行操作并返回结果。
  示例:
  val result = "Hello".let { it.uppercase() } // "HELLO"
  val result2 = "Hello".also { println(it) } // prints "Hello", returns "Hello"
  val result3 = "Hello".run { uppercase() } // "HELLO"
- DSL(Domain specific language)
  DSL 是针对特定领域的语言，用于简化复杂任务。
  示例: Kotlin 的 HTML DSL。
  ```kotlin
  html {
    body {
      h1 { +"Hello" }
    }
  }
  ```
- 泛型
  泛型允许类型参数。
  - In(消费者， 只修改)
  - Out(生成者， 只获取)
  示例: class Box<out T>(val value: T)
- 注解
  注解用于元数据。
  示例: @Retention(AnnotationRetention.RUNTIME)
  class MyClass
- 协程
  协程用于异步编程。
  示例:
  ```kotlin
  suspend fun fetchData() { ... }
  ```

## 安卓知识点
- lifeCycle
  Activity 的生命周期，包括 onCreate, onStart, onResume, onPause, onStop, onDestroy 等阶段，用于管理 Activity 的状态。
- liveData
  LiveData 是可观察的数据持有者类，遵循生命周期。当数据更新时，观察者会收到通知。
- viewBinding
  ViewBinding 提供类型安全的视图绑定，替代 findViewById，减少错误。
- viewModel
  ViewModel 管理 UI 相关数据，在配置更改（如屏幕旋转）时保留数据。
- viewModelStore
  ViewModelStore 存储 ViewModel 实例的容器。
- AMS(ActivityManagerService)
  AMS 是 Android 系统服务，负责管理 Activity 的启动、暂停、恢复等。
- IBinder
  IBinder 是用于进程间通信的接口，AIDL 使用它。
